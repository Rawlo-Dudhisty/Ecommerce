# 🛒 Static E-commerce Website (HTML & CSS)

A clean and responsive **static e-commerce website** built using only **HTML5 and CSS3**.  
This project focuses on layout design, responsiveness, and modern UI principles without using JavaScript.

---

## 🚀 Features

- 🏠 Home page with banner and featured products
- 🛍️ Product listing section with product cards
- 📄 Product detail layout (UI only)
- 🧭 Navigation bar and footer
- 📱 Fully responsive design
- 🎨 Modern and clean UI

---

## 🧰 Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Styling and layout
  - Flexbox
  - Grid
  - Media Queries
